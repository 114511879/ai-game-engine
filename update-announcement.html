AI 游戏引擎更新公告

2026 年 8 月 2 日
全新聊天式 UI · 本地记忆系统 · 独立游戏页面
✨ 新增功能
💬 聊天式交互界面
采用 AI 网页统一风格，从单页游戏容器升级为完整聊天体验
  • 侧边栏：品牌标识、新对话按钮、历史对话列表、一键清空
  • 聊天区：欢迎页含 6 个建议芯片，消息气泡区分用户/AI 头像
  • 底部输入栏：5 种游戏预设快捷按钮 + 导演/测试模式 + 发送按钮
  • 响应式布局，移动端侧边栏自动隐藏
🧠 localStorage 记忆系统
对话与游戏数据持久化存储，下次打开即可恢复
  • 对话历史持久化 age_conversations_v10
  • 游戏 DSL 独立存储 age_game_{convId}
  • 点击侧边栏历史项即可恢复完整对话与游戏卡片
🎮 独立游戏页面（新标签页）
点击游戏卡片即可在新标签页打开完整游戏
  • 从 URL 参数读取对话 ID，自动加载 localStorage 游戏数据
  • 返回对话页按钮、重新开始按钮
  • 游戏结束自动提示重开
  • 数据不存在时显示友好错误页面
⌨️ 快捷键支持
  • Ctrl+Shift+K 新建对话
  • Enter 发送消息
  • Shift+Enter 换行
🔄 修改
index.html — 布局重构
从单页游戏容器重构为侧边栏 + 主区域的聊天布局
styles.css — 主题升级
从深色游戏主题改为 AI 网页统一风格（白色主题 + 紫色强调色 #4b3fe3）
main.js — 架构重写
从命令式按钮重写为 ChatUI + Memory 双模块架构
  • 引擎初始化保留（隐藏 canvas 供导演/测试模式后台使用）
  • Memory 模块管理 localStorage 全部读写
  • ChatUI 模块管理聊天交互全流程
  • 三种生成模式保留：普通生成、生成+测试（3轮优化）、AI 导演
🔧 修复
弹窗拦截问题 已修复
游戏卡片「在新标签页打开」按钮被浏览器弹窗拦截器阻止。
从 window.open() 改为 <a target="_blank"> 标准链接。
对话重复记录 已修复
已有对话更新时产生重复记录。
新对话使用 Memory.add()，已有对话使用 Memory.update()。
