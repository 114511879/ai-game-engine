# Android Debug APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an Android Studio project that automatically packages the current web application into an installable Debug APK on every build.

**Architecture:** A dependency-free Android Activity hosts the trusted packaged web application in a WebView. Gradle validates and synchronizes selected repository-root web files into generated Android assets before every build, so no manually maintained asset copy exists.

**Tech Stack:** Android Gradle Plugin 7.4.1, Gradle 7.5, Java 11, Android SDK 33, native Android WebView, PowerShell/ADB verification.

---

The workspace is not a Git repository. Do not initialize Git as part of this task; use the verification checkpoint at the end of each task instead of commit steps.

`android/app/build.gradle`:

```groovy
plugins {
    id 'com.android.application'
}

def webRoot = rootProject.projectDir.parentFile
def generatedWebAssets = layout.buildDirectory.dir('generated/webAssets')
def requiredWebFiles = [
    'index.html',
    'AI-ENGINE启动.html',
    'main.js'
]
def synchronizedRootFiles = [
    'index.html',
    'AI-ENGINE启动.html',
    'game.html',
    'update-announcement.html',
    'styles.css',
    'main.js'
]
def synchronizedDirectories = [
    'ai',
    'assets',
    'core',
    'fitness',
    'plugins'
]

tasks.register('validateWebSources') {
    inputs.files(requiredWebFiles.collect { new File(webRoot, it) })
    doLast {
        def missing = requiredWebFiles.findAll { !new File(webRoot, it).isFile() }
        if (!missing.isEmpty()) {
            throw new GradleException('Missing required web sources: ' + missing.join(', '))
        }
    }
}

tasks.register('syncWebAssets', Sync) {
    dependsOn tasks.named('validateWebSources')
    from(webRoot) {
        synchronizedRootFiles.each { include it }
        synchronizedDirectories.each { include it + '/**' }
        exclude '**/__pycache__/**'
        exclude '**/*.pyc'
    }
    into(generatedWebAssets.map { it.dir('web') })
}

tasks.register('verifyWebAssetSync') {
    dependsOn tasks.named('syncWebAssets')
    doLast {
        def destinationRoot = new File(generatedWebAssets.get().asFile, 'web')

        synchronizedRootFiles.each { relativePath ->
            def source = new File(webRoot, relativePath)
            def packaged = new File(destinationRoot, relativePath)
            if (!source.isFile() || !packaged.isFile()) {
                throw new GradleException('Missing synchronized file: ' + relativePath)
            }
            if (!java.util.Arrays.equals(source.bytes, packaged.bytes)) {
                throw new GradleException('Synchronized file is stale: ' + relativePath)
            }
        }

        synchronizedDirectories.each { relativePath ->
            if (!new File(destinationRoot, relativePath).isDirectory()) {
                throw new GradleException('Missing synchronized directory: ' + relativePath)
            }
        }

        ['android', 'docs', 'server', 'tests'].each { excludedPath ->
            if (new File(destinationRoot, excludedPath).exists()) {
                throw new GradleException('Excluded path was packaged: ' + excludedPath)
            }
        }
    }
}

android {
    namespace 'com.aigameengine.app'
    compileSdk 33

    defaultConfig {
        applicationId 'com.aigameengine.app'
        minSdk 26
        targetSdk 33
        versionCode 1
        versionName '1.0-debug'
    }

    buildTypes {
        debug {
            debuggable true
        }
    }

    sourceSets {
        main {
            assets.srcDir(generatedWebAssets)
        }
    }
}

tasks.named('preBuild').configure {
    dependsOn tasks.named('syncWebAssets')
}
```

`android/app/src/main/java/com/aigameengine/app/MainActivity.java`:

```java
package com.aigameengine.app;

import android.annotation.SuppressLint;
import android.app.Activity;
import android.content.ActivityNotFoundException;
import android.content.Intent;
import android.graphics.Color;
import android.net.Uri;
import android.os.Build;
import android.os.Bundle;
import android.view.ViewGroup;
import android.webkit.WebChromeClient;
import android.webkit.WebResourceError;
import android.webkit.WebResourceRequest;
import android.webkit.WebSettings;
import android.webkit.WebView;
import android.webkit.WebViewClient;

public final class MainActivity extends Activity {
    private static final String APP_URL = "file:///android_asset/web/index.html";
    private static final String ERROR_HTML =
            "<!doctype html><html><head><meta name=\"viewport\" content=\"width=device-width,initial-scale=1\">"
            + "<style>body{margin:0;background:#111827;color:#f9fafb;font-family:sans-serif;display:grid;"
            + "place-items:center;min-height:100vh;text-align:center}main{padding:24px}button{border:0;border-radius:6px;"
            + "padding:12px 18px;background:#18a66a;color:white;font-size:16px}</style></head>"
            + "<body><main><h1>Page failed to load</h1><p>The packaged application could not be opened.</p>"
            + "<button onclick=\"location.href='" + APP_URL + "'\">Retry</button></main></body></html>";

    private WebView webView;

    @SuppressLint("SetJavaScriptEnabled")
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);

        webView = new WebView(this);
        webView.setBackgroundColor(Color.rgb(17, 24, 39));
        setContentView(webView, new ViewGroup.LayoutParams(
                ViewGroup.LayoutParams.MATCH_PARENT,
                ViewGroup.LayoutParams.MATCH_PARENT));

        WebSettings settings = webView.getSettings();
        settings.setJavaScriptEnabled(true);
        settings.setDomStorageEnabled(true);
        settings.setAllowFileAccess(true);
        settings.setAllowContentAccess(false);
        settings.setAllowFileAccessFromFileURLs(true);
        settings.setAllowUniversalAccessFromFileURLs(true);
        settings.setLoadWithOverviewMode(true);
        settings.setUseWideViewPort(true);
        settings.setMediaPlaybackRequiresUserGesture(false);
        settings.setJavaScriptCanOpenWindowsAutomatically(false);
        settings.setSupportMultipleWindows(false);
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.LOLLIPOP) {
            settings.setMixedContentMode(WebSettings.MIXED_CONTENT_ALWAYS_ALLOW);
        }

        WebView.setWebContentsDebuggingEnabled(BuildConfig.DEBUG);
        webView.setWebChromeClient(new WebChromeClient());
        webView.setWebViewClient(new WebViewClient() {
            @Override
            public boolean shouldOverrideUrlLoading(WebView view, WebResourceRequest request) {
                return openExternalIfNeeded(request.getUrl());
            }

            @Override
            @SuppressWarnings("deprecation")
            public boolean shouldOverrideUrlLoading(WebView view, String url) {
                return openExternalIfNeeded(Uri.parse(url));
            }

            @Override
            public void onReceivedError(
                    WebView view,
                    WebResourceRequest request,
                    WebResourceError error) {
                if (request.isForMainFrame()) {
                    showLoadError();
                }
            }
        });

        if (savedInstanceState == null || webView.restoreState(savedInstanceState) == null) {
            webView.loadUrl(APP_URL);
        }
    }

    private boolean openExternalIfNeeded(Uri uri) {
        if ("file".equalsIgnoreCase(uri.getScheme())) {
            return false;
        }
        try {
            startActivity(new Intent(Intent.ACTION_VIEW, uri));
        } catch (ActivityNotFoundException ignored) {
            // The WebView remains on the current trusted local page.
        }
        return true;
    }

    private void showLoadError() {
        webView.loadDataWithBaseURL(APP_URL, ERROR_HTML, "text/html", "UTF-8", APP_URL);
    }

    @Override
    protected void onSaveInstanceState(Bundle outState) {
        webView.saveState(outState);
        super.onSaveInstanceState(outState);
    }

    @Override
    public void onBackPressed() {
        if (webView != null && webView.canGoBack()) {
            webView.goBack();
        } else {
            super.onBackPressed();
        }
    }

    @Override
    protected void onDestroy() {
        if (webView != null) {
            webView.stopLoading();
            webView.setWebChromeClient(null);
            webView.setWebViewClient(null);
            webView.destroy();
            webView = null;
        }
        super.onDestroy();
    }
}
```

````markdown
# Android Debug APK

Open this `android` directory in Android Studio.

## Build

Use **Build > Build Bundle(s) / APK(s) > Build APK(s)**, or run from the repository root:

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
android\gradlew.bat -p android :app:assembleDebug --offline
```

The APK is written to:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Every build validates and copies the current web source from the repository root. After editing HTML, CSS, JavaScript, or files under `ai`, `assets`, `core`, `fitness`, or `plugins`, rebuild and reinstall the APK. No manual asset copy is needed.

An APK already installed on a phone does not change automatically. Install the newly built APK over the existing app to update it.

## Install

With a device or emulator connected:

```powershell
& 'C:\Users\administered0\AppData\Local\Android\Sdk\platform-tools\adb.exe' install -r 'android\app\build\outputs\apk\debug\app-debug.apk'
```

The packaged web app can use HTTPS APIs when the device has network access. The existing RAG URL `http://127.0.0.1:8765` points to the Android device itself, so the app normally uses its existing offline fallback unless a compatible service runs on the device.
````
